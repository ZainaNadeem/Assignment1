# Aaron Leeb Resume Website

A responsive, one-page resume website built with HTML, custom CSS, JavaScript, and Bootstrap 5.

## Run locally

Open `index.html` directly in a browser. An internet connection is needed for the Bootstrap and Google Fonts CDN files.

You can also serve the folder with VS Code Live Server or run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
